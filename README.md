# 🕌 Quran Zekr - تطبيق القرآن الكريم

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![GitHub Sponsors](https://img.shields.io/github/sponsors/ZOOKA-AI?style=social)](https://github.com/sponsors/ZOOKA-AI)

A comprehensive Quran application built with React and Base44, providing a complete Islamic experience including Quran reading, prayer times, recitations, and more.

## ✨ Features

- 📖 **Quran Reading**: Complete Quran with Arabic text and translations
- 🎧 **Audio Recitations**: Listen to various Qaris reciting the Holy Quran
- 🕌 **Prayer Times**: Accurate prayer times based on your location
- 🔖 **Bookmarks**: Save your favorite verses and continue where you left off
- 🎨 **Islamic Calligraphy**: Beautiful Arabic calligraphy display
- 🤖 **AI Assistant**: Islamic knowledge assistant powered by AI
- 📢 **Notifications**: Customizable prayer time notifications
- 🌙 **Tilawa**: Continuous recitation mode for uninterrupted listening
- 👤 **User Profile**: Personalized experience with user preferences

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/ZOOKA-AI/quran.zekr.by.zooka-ai.com.git
cd quran.zekr.by.zooka-ai.com
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## 🛠️ Available Scripts
