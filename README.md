# Zekr AI - Quran Application

## مرحباً بك في تطبيق ذكر الله

Welcome to Zekr AI, a modern application dedicated to Quranic knowledge and Islamic learning powered by artificial intelligence.

## Features

- 📖 Complete Quran with translations
- 🤖 AI-powered Quranic insights
- 🔍 Advanced search functionality
- 🌍 Multi-language support
- 📱 Responsive design
- ⭐ Personalized learning experience

## Installation

1. Clone the repository
```bash
git clone https://github.com/ZOOKA-AI/quran.zekr.by.zooka-ai.com.git
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm start
```
