# Quran & Zekr Application

A comprehensive Islamic application featuring Quran reading, prayer times, dhikr, and more.

## SEO Optimization

This application is optimized for search engines with:
- ✅ Comprehensive meta tags (Open Graph, Twitter Cards)
- ✅ XML sitemap for all pages
- ✅ robots.txt for crawler guidance
- ✅ Schema.org structured data
- ✅ PWA manifest for mobile installation
- ✅ Bilingual support (Arabic & English)

For detailed SEO implementation and maintenance guide, see [SEO_GUIDE.md](./SEO_GUIDE.md).

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Features

- 📖 Quran reading with multiple reciters
- 🕌 Prayer times based on location
- 📿 Daily dhikr and supplications
- 📻 Quran radio streaming
- 🌙 Ramadan features
- ✍️ Islamic calligraphy
- 📚 Islamic library
- 👥 Community features

## SEO Files

- `/public/robots.txt` - Search engine crawler instructions
- `/public/sitemap.xml` - Complete sitemap of all pages
- `/public/manifest.json` - PWA manifest for mobile installation
- `/index.html` - Enhanced with comprehensive meta tags
