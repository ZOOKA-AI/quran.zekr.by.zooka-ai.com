## 🔧 Manual Steps Required (on GitHub.com)

The following steps must be completed manually through the GitHub web interface:

### 1. Make Repository Public

**Steps:**
1. Go to repository Settings
2. Scroll down to the "Danger Zone" section
3. Click "Change repository visibility"
4. Select "Make public"
5. Type the repository name to confirm
6. Click "I understand, change repository visibility"

**Alternative URL:** 
`https://github.com/ZOOKA-AI/quran.zekr.by.zooka-ai.com/settings`

### 2. Enable GitHub Sponsors

**Steps:**
1. Go to your profile or organization page
2. Click on "Sponsor" or go to Settings
3. Navigate to GitHub Sponsors
4. Complete the sponsor profile setup:
   - Add a profile description
   - Set sponsorship tiers (optional)
   - Add payment information
5. Submit for review

**Note:** The `FUNDING.yml` file is already configured and will automatically show the sponsor button once GitHub Sponsors is enabled for ZOOKA-AI.

**Alternative URL:**
`https://github.com/sponsors/ZOOKA-AI`

### 3. Repository Settings to Review

After making the repository public, consider reviewing these settings:

- **Issues**: Enable/Disable issue tracker (recommend: Enable)
- **Discussions**: Enable for community engagement (recommend: Enable)
- **Wiki**: Enable if you plan to add documentation (optional)
- **Projects**: Enable for project management (optional)
- **Sponsorships**: Will automatically show sponsor button if configured
